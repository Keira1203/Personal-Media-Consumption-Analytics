# Personal Media Consumption Analytics

This project explores how personal digital behavior relates to daily routines, media consumption, and study habits.  
It focuses on analyzing patterns from YouTube watch history, Apple Music listening data, and study time records.

## Project Goal

The aim is to understand correlations between entertainment use and study patterns, identify trends, and visualize weekly and monthly routines.  
Insights from this project can help improve time management and balance between work, study, and leisure.

## Data Sources

- **YouTube watch history**  
- **Apple Music listening history**  
- **Study time logs**  

> All raw personal data is kept private and is not included in this repository.

## Tech Stack

- Python  
- pandas  
- matplotlib  
- Jupyter Notebook
- SQLite

## Monthly Reports

Monthly analysis reports are stored in the `reports/` folder.  
They summarize the top content, usage patterns, and correlations between entertainment and study behavior for each month.

## Privacy Note

This repository contains **no personally identifiable information**.  
All raw data has been processed or anonymized before analysis.
